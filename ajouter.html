Comment ajouter une notion

Tout le contenu du manuel est dans un seul fichier : manuel/donnees/notions.js. Les pages, le sommaire, la recherche et le glossaire se mettent à jour tout seuls.

  1. Choisir le chapitre. Ouvrir notions.js et repérer le chapitre (les lignes // ── 1. Git, // ── 2. …). Si aucun ne convient, en créer un nouveau sur le modèle d'un chapitre existant (id, titre, resume, intro, notions).
  2. Vérifier que la notion n'existe pas déjà. La chercher avec la barre de recherche (/). Si elle existe, compléter la fiche au lieu d'en créer une seconde.
  3. Copier ce modèle à la fin de la liste notions: [ … ] du chapitre, après une virgule : 
    { id: 'chapitre-mot-cle', titre: 'Titre court de la notion',
  definition: `<p>Une ou deux phrases simples.</p>`,
  exemple: `<p>Un cas concret, si possible tiré du stage.</p>`,
  schema: `<div class="flux"><span class="etape">Étape 1</span><span class="fleche">→</span><span class="etape">Étape 2</span></div>`,
  image: `Une comparaison de la vie courante pour s'en souvenir.`, icone: '💡',
  retenir: `<div class="a-retenir">La phrase à retenir.</div>`,
  termes: [['Mot', 'Sa définition en une phrase.']] },
  4. Ne garder que l'utile. id, titre et definition sont obligatoires ; supprimer les autres lignes si elles n'apportent rien. Une fiche courte se relit mieux qu'une fiche complète.
  5. Vérifier. Recharger la page du chapitre (Ctrl + F5) : la fiche apparaît, avec son entrée dans le sommaire du chapitre, la recherche et le glossaire.
  6. Enregistrer dans Git. git add manuel puis git commit -m "manuel: fiche …".

Les blocs disponibles

ChampAffiché commeAstuce
definitionDéfinitionObligatoire. Mots simples, pas de jargon non défini.
exempleExempleCode dans <pre><code>…</code></pre>.
schemaSchémaChaîne d'étapes (flux), tableau (table-wrap) ou dessin en texte dans <pre>.
image + iconeImage pour retenirUne comparaison concrète (restaurant, usine…) et un émoji.
retenirÀ retenirClasse a-retenir (bleu) ou attention (rose) pour un piège.
termesGlossaireUn terme déjà défini ailleurs n'apparaît qu'une fois : reprendre la même définition.
Pièges : une apostrophe dans un texte entre '…' s'écrit \' ; les textes entre accents graves `…` l'acceptent telle quelle. Ne jamais écrire de mot de passe ni de jeton dans le manuel.
