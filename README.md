# Manuel de cours

Application éducative personnelle : notions d'informatique (Git, API, CI/CD, mise en ligne, sécurité…) avec définitions, schémas, exemples et glossaire.

Site statique : ouvrir `index.html` dans un navigateur. Les notions sont dans `donnees/notions.js`.

Les exemples tirés de mon alternance sont anonymisés (noms de projets, de personnes et adresses internes remplacés).
